# Инструкции для агентов

## Доска задач

Проект Kanboard: `grim` (ID `21`), [доска](http://localhost/board/21).
Ведите работу через скилл `kanboard-taskboard`. Направление постепенного
объединения с llm-coreader зафиксировано в [задаче #2375](http://localhost/task/2375).

При создании или редактировании объясняющих материалов Grim сначала прочитайте и соблюдайте руководство для соответствующего формата:

- Для учебных книг — [«Как писать учебные материалы»](docs/how-to-write-learning-materials.md).
- Для учебных видео — [«Как создавать учебные видео»](docs/how-to-make-learning-videos.md).

Руководства являются рабочими: дополняйте их только правилами, которые явно сформулировал пользователь или которые пользователь отдельно одобрил. Не превращайте единичную редакторскую правку в общее правило без такого основания.
