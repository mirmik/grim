# Как создавать учебные видео

Рабочие рекомендации по подготовке обучающих роликов. Рекомендации для
книг находятся отдельно: [«Как писать учебные материалы»](how-to-write-learning-materials.md).
Этот документ фиксирует согласованные требования к изложению и текущие
инструменты; набор библиотек можно расширять по мере новых экспериментов.

## 1. Последовательное изложение без затягивания

Материал должен развиваться последовательно: каждый следующий шаг
опирается на уже объяснённое и продвигает зрителя дальше по теме.
Не нужно несколько раз повторять объяснение, которое уже дано.

Затянутость определяется неоправданным повторением, а не общей
длительностью ролика. При редактировании следует убирать повторы,
сохраняя время, необходимое для понимания и наблюдения за анимацией.
Не следует ужимать материал до сжатого пересказа ради короткого тайминга.

## 2. Видео к книге формирует интуицию

Видео, прилагающееся к главе, выполняет роль **иллюстративного материала**.
Его задача — сформировать у читателя интуицию об объектах, которые
исследуются в главе: показать, как они устроены, как меняются и что
означают изучаемые связи. Не следует строить такой ролик как пересказ
или полное изложение главы.

Видео должно быть полезно в обоих порядках просмотра:

- **До чтения** — подготовить к формулам в тексте, чтобы читатель
  приступал к ним с пониманием происходящего.
- **После чтения** — дать наглядную иллюстрацию уже изученным формулам
  и связать их с поведением объектов.

**Формулы в видео нужны**, но акцент следует делать на их наглядном
смысле и связи с изображением. Не нужно перегружать ролик подробным
разбором формул или пошаговыми численными примерами: за время просмотра
читатель не успеет обстоятельно изучить запись или проследить вычисления.
Подробности остаются в тексте книги, к которому можно возвращаться
и который можно изучать в собственном темпе.

## 3. Инфографика и анимация

Для построения инфографики рекомендуется **Manim**. В текущем прототипе
используется Manim Community: трёхмерные поверхности, стрелки, графики,
деформации и векторные формулы создаются как объекты сцен.

Manim — текущий рекомендуемый инструмент. Позже можно подобрать
дополнительные библиотеки для других задач визуализации.

Рабочий пример — [ролик по дифференциальной геометрии](../experiments/spherical-geometry-manim/README.md).
В нём используются рендерер Cairo, `MathTypst` для формул и `Text` для
русских подписей. FFmpeg объединяет видео с озвучкой и кодирует итоговые файлы.

## 4. Генерация озвучки

Сейчас для синтеза речи используем **VoxCPM2** (`openbmb/VoxCPM2`),
запускаемую локально через PyTorch на GPU. Голос задаётся образцом записи;
в текущих экспериментах это `~/project/for-tts-xtts/reference.wav`.

Текст **каждой сцены озвучивается целиком одним запросом**. В сравнении
вариантов пользователь предпочёл этот способ отдельной генерации каждого
предложения: интонация внутри сцены получается более связной.
Разбиение на предложения используется для субтитров и временных меток,
при этом сама запись сцены остаётся непрерывной.

Текущие параметры генерации: `cfg_value=2.0`, `inference_timesteps=10`,
`seed=42`; исходные записи сохраняются в WAV с частотой 48 кГц.
Полные настройки и закреплённая ревизия модели находятся в
[скрипте синтеза](../experiments/beam-bending/synthesize_voxcpm.py).

Окружение синтеза — `experiments/voxcpm2/.venv`. Пример применения
озвучки целыми сценами — [synthesize.py](../experiments/spherical-geometry-v6/synthesize.py).
Текущий [ролик на Manim](../experiments/spherical-geometry-manim/README.md)
использует уже готовую дорожку VoxCPM2 и её временные метки для
синхронизации анимации с рассказчиком.
