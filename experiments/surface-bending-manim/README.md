# Видео к главе «Как поверхность изгибается»

Ролик на 5:36 для второй главы книги «Дифференциальная геометрия» в Grim.
Содержание следует главе: поле нормалей, отображение Гаусса, производная
нормали, оператор формы, вторая форма, нормальные сечения и формула Эйлера,
вычисление для квадратичного графика, седло, цилиндр и сфера.

- [Готовое видео](output/normal-and-curvature.mp4)
- [Сценарий](script.json) · [анимация](lesson.py) · [геометрия и проверки](geometry.py)
- [Субтитры](output/subtitles.vtt) · [расшифровка](output/narration.md)

Графика — Manim Community 0.21.0, Cairo, `MathTypst` и `Text`.
Используется окружение и планировщик кадров из
[предыдущего эксперимента](../spherical-geometry-manim/README.md);
все сцены и озвучка этого ролика новые. Для секущей плоскости выбран
ракурс, в котором она видна на всём повороте от 0 до 90°.

Озвучка — локальная VoxCPM2 с прежним образцом голоса. Каждая из 11 сцен
записана целиком, без ускорения и внутренних склеек. Между записями
добавлено по 0,35 секунды. Локальный Whisper используется для проверки
текста и приблизительной расстановки субтитров; это не оценка ударений
или интонации. Субтитры включаются отдельно в проигрывателе.

Соглашения совпадают с книгой: `S = −dn`, для квадратичного графика нормаль
направлена вверх, для цилиндра и первой части сцены со сферой — наружу.
В начале графика `z = (u² + 3v²)/2` получаем `k₁ = 1`, `k₂ = 3`;
в конце деформации `z = (u² − v²)/2` получаем седло с `K = −1`, `H = 0`
именно в центральной точке. При развёртке цилиндра длины сохраняются.
Определения и формула Эйлера сверены с
[конспектом Александра Риттера, §§11–12](https://people.maths.ox.ac.uk/ritter/geometry-of-surfaces/ritter-geom-surf-67.pdf).
Документация графической основы —
[Manim ThreeDScene](https://docs.manim.community/en/stable/reference/manim.scene.three_d_scene.ThreeDScene.html).

## Сборка и установка

```bash
bash experiments/surface-bending-manim/run.sh
python3 experiments/surface-bending-manim/install.py
node experiments/surface-bending-manim/verify_player.mjs
```

Установка выполняется после успешного `validate.py`. Она находит
существующую книгу в `.grim/library.json`, копирует файлы в её
`assets/video/` и добавляет проигрыватель после вводного абзаца главы.
Для другого экземпляра книги: `install.py --book-root /absolute/path`.
Основной текст и прежние иллюстрации главы сохраняются.

Проигрыватель использует HTML `<video controls playsinline>` с MP4
H.264/AAC, постером, русскими WebVTT-субтитрами и переходами к частям
ролика. Автоматического старта нет. Все ресурсы находятся внутри папки
книги и доступны по относительным путям; отдельный видеосервис не нужен.
Grim разрешает полноэкранный просмотр внутри песочницы страницы.

Проверки в `output/validation.json` сравнивают кадры MP4 со снимками Manim,
проверяют движение геометрии, геометрические тождества, целостность
исходных WAV и полное декодирование файла. Браузерная проверка проверяет
воспроизведение, перемотку, субтитры, полноэкранный режим, скачивание,
HTTP Range и мобильную вёрстку уже установленной главы.
