# Кривизна изнутри — версия на Manim

[Полный ролик, 7:42](output/spherical-geometry-manim-ru.mp4) ·
[Начало, 1:14](output/opening-manim.mp4) ·
[RGB WebM для VLC](output/spherical-geometry-manim-rgb.webm)

Все 18 сцен пересозданы на Manim Community 0.21.0. Сценарий, целая дорожка
VoxCPM2 и границы сцен взяты из шестой редакции. После обхода стрелки
сразу начинается объяснение результата. Новых пауз или реплик нет.

Графика в [lesson.py](lesson.py):

- `ThreeDScene`, `Surface`, `Arrow3D` и векторные кривые для сферы,
  параллельного переноса и касательной плоскости.
- Изменение геодезического треугольника, график зависимости избытка
  от радиуса и стягивание треугольника к точке.
- Нормальные сечения и изменение формы поверхности при объяснении знака
  кривизны, сворачивание листа с сохранением нарисованного треугольника.
- Деформация сферы в эллипсоид и окраска положительной и отрицательной
  кривизны тора.
- Векторные формулы `MathTypst`, русские подписи `Text` и появление
  формул по временным меткам рассказчика.

Используется программный рендерер Cairo. Pillow применяется только
для проверки изображений и сборки контрольных листов. Готовые кадры
предыдущего рендера в сцены не вставляются.

Геометрические вычисления сохранены в [geometry.py](geometry.py):
перенос вдоль дуг больших окружностей, касательность и длина вектора,
избыток и площадь, изометрическое сворачивание листа, интегралы кривизны.
Проверки готового видео находятся в [validate.py](validate.py).
Они сопоставляют кадры с отдельными снимками Manim, проверяют движение
стрелки, число кадров, декодирование и побайтовое совпадение исходной
озвучки с v6.

FFmpeg собирает постоянные 30 кадров/с по номерам кадров отдельных сцен,
чтобы округление временных меток промежуточных контейнеров не накапливало
рассинхронизацию. MP4 использует H.264 Constrained Baseline и BT.709.
Дополнительный VP9 RGB файл предназначен для проверки другого пути
воспроизведения в VLC. Пользовательский видеовывод VLC этими проверками
не тестируется.

## Повторная сборка

```bash
bash experiments/spherical-geometry-manim/setup.sh
bash experiments/spherical-geometry-manim/run.sh
```

Зависимости закреплены в [requirements.lock.txt](requirements.lock.txt).
Окружение `.venv` находится внутри эксперимента. Если в текущей Ubuntu 24.04
нет заголовков Pango, `bootstrap_native.py` извлекает официальные пакеты
в локальную `.native`, используя уже установленные системные библиотеки.
Системные пакеты и настройки не меняются.
