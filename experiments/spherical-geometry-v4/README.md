# Кривизна изнутри — последовательное объяснение

[Ролик MP4](output-voxcpm-scenes/spherical-geometry-ru.mp4) ·
[RGB WebM для проверки в VLC](output-voxcpm-scenes/spherical-geometry-rgb.webm) ·
[Текст нового начала](opening.md) ·
[Субтитры](output-voxcpm-scenes/subtitles.srt)

Четвёртая редакция переписывает начало как последовательный опыт.
Сначала ставится вопрос, затем строится путь и объясняется правило переноса.
Во время движения рассказчик помогает следить за происходящим на каждом
участке. Убран повтор правила внутри обхода; длительность определяется
объяснением и временем на наблюдение.

- 00:00 — вопрос и цель опыта.
- 00:25 — построение пути и геодезические на сфере.
- 01:02 — касательная плоскость и правило переноса на неподвижной стрелке.
- 01:37 — движение по трём сторонам с остановками в вершинах.
- 02:07–02:12 — наблюдение результата после возвращения.
- 02:12 — сравнение направлений и угловой избыток.
- 02:45 — площадь, затем кривизна и дальнейшее обобщение.

Полная длительность — 9:13. Первые пять сцен написаны и озвучены заново.
Остальные 15 записей сохранены из третьей редакции. VoxCPM2 читает каждую
сцену целиком, прежним голосом и с прежними настройками. Скорость речи
не меняется. `pace.py` собирает исходные записи без изменения отсчётов
и добавляет паузу после опыта; субтитры выравниваются отдельно.

`check_frames.py` сравнивает кадры готового файла с рендером и проверяет
три положения движущейся стрелки. `validate.py` проверяет геометрию,
сборку исходного аудио, тайминг и полное декодирование MP4.

Основной файл — H.264 Constrained Baseline с явной матрицей BT.709.
Запасной — VP9 Profile 1 RGB, без потерь на этапе повторного кодирования.
Он позволяет проверить другой путь воспроизведения в VLC; устранение
артефактов на пользовательском видеовыводе пока не подтверждено.

Запуск VLC без аппаратного декодирования и с X11-выводом:

```bash
bash experiments/spherical-geometry-v4/play-vlc-software.sh
```

Полная сборка:

```bash
bash experiments/spherical-geometry-v4/run.sh
```

Сценарий — [script.json](script.json). Математические пояснения и источники
сохранены во [второй редакции](../spherical-geometry-v2/README.md).
