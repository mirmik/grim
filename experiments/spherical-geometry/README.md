# Треугольник с тремя прямыми углами

Учебный ролик: геодезические на сфере, треугольник с углами 90°,
параллельный перенос, угловой избыток, треугольная форма теоремы
Гаусса — Бонне, седло и изометрическое сворачивание листа.

## Озвучка

VoxCPM2, обычное клонирование голоса: `reference_wav_path` без стилевой
инструкции и без continuation prompt. Каждая сцена сгенерирована одним
непрерывным фрагментом. Использован тот же голос, что в предыдущем ролике
про консольную балку: `~/project/for-tts-xtts/reference.wav`.

Модель `openbmb/VoxCPM2`, revision
`32279effe8c19989596f05d353d1447f51d9e915`; voxcpm 2.0.3.
Seed 42 перед каждой генерацией, CFG 2, 10 шагов, `max_len=700`,
`normalize=False`, `denoise=False`, `retry_badcase=False`, без torch.compile.
Оригинальные записи float32, 48 кГц. Пауза перед сценой 0,35 с,
после сцены 0,8 с; ещё 1 с в конце. Длительность WAV 450,02 с.
Суммарное время генерации 18 сцен на RTX 5090 — 110,13 с без загрузки модели.

Субтитры разбиты на предложения по приблизительным временным привязкам
Whisper small. **Звуковая дорожка внутри сцен не разрезается.**
Распознавание служит проверкой содержания, а не ударений и интонации.
Исходный ASR для сцены 05 приписал короткому хвосту записи фиктивные
«титры»; дополнительные результаты проверки с VAD сохранены в
`tail-review.json`. Исходная запись не подрезалась и не заменялась.

## Математика и визуализация

Все поверхности, кривые и векторы строятся кодом. Растровая отрисовка
Pillow, формулы matplotlib mathtext, кодирование FFmpeg: H.264,
1920×1080, 30 кадров/с, AAC 48 кГц. Для MP4 применяется нормализация
громкости до −16 LUFS с ограничением true peak −1,5 dB.

Сфера единичная. Маршрут: N=(0,0,1) → A=(1,0,0) →
Б=(cos φ,sin φ,0) → N. Начальный касательный вектор (1,0,0).
На каждой дуге большой окружности точка и вектор поворачиваются вокруг
нормали её плоскости по формуле Родрига. Это точный параллельный перенос
для индуцированной метрики сферы: касательная компонента производной
вектора равна нулю. Итоговый вектор (cos φ,sin φ,0).
В основном примере φ=π/2. Отдельная вставка показывает касательную
плоскость сверху, чтобы проекция не искажала демонстрируемый прямой угол.

Площадь и углы сверяются независимыми вычислениями: углы через скалярные
произведения касательных, площадь через телесный угол трёх вершин.
На сфере угловой избыток E=A/R². Для простой геодезической границы
треугольной области, топологически являющейся диском, E=∫ K dA.
Седло показано как поверхность z=0,36(x²−y²); геодезический треугольник
на седле не моделируется. Цветные сечения проходят через его центр.

Сворачивание листа задано отображением
F(x,y)=(sin(bx)/b, y, (1−cos(bx))/b), с плоским пределом при b=0.
Оно сохраняет метрику dx²+dy². Поэтому нарисованный на листе треугольник
сохраняет внутренние углы при изгибе, хотя его проекция меняется.

### Учебные источники

- [Paul Bryan, Lectures on Differential Geometry](https://pabryan.au/pdf/teaching/dg/dg.pdf),
  §5.2, особенно пример на страницах PDF 89–90: параллельный перенос
  вокруг сферического октанта и голономия.
- [Hunter S. Chase, Fundamental Forms of Surfaces and the Gauss–Bonnet Theorem](https://math.uchicago.edu/~may/REU2012/REUPapers/Chase.pdf),
  §3–4: гауссова кривизна, её внутренняя природа и формула для
  геодезических многоугольников. В сценарии явно оговорены область без
  дыр и геодезические стороны.

## Воспроизведение и проверки

Из корня репозитория:

```bash
bash experiments/spherical-geometry/run.sh
```

Используются уже установленные окружения предыдущего эксперимента.
VoxCPM2 и её веса нужны локально; для синтеза требуется доступ к CUDA.
Whisper small использует кэш `/tmp/grim-video-whisper`.
Путь Python можно переопределить через `VOX_PYTHON` и `VIDEO_PYTHON`.

`synthesize.py` переиспользует проверенный синтез из `beam-bending`,
сохраняя новые результаты в собственной папке. `drawing.py` содержит
локальную копию небольших функций рисования из предыдущего ролика.
Предыдущие видео не изменяются.

`geometry.py` проверяет углы, площадь, результат переноса, касательность,
сохранение длины вектора, отсутствие его собственного поворота и метрику
сворачиваемого листа. `validate.py` проверяет фактически закодированный
MP4, полное декодирование, длительности, границы субтитров и совпадение
всех сцен с исходными WAV по каждому отсчёту до нормализации MP4.
Результат — `output-voxcpm-scenes/validation.json`.

Для проверки композиции рендерятся начало, середина и конец каждой сцены:

```bash
python3 experiments/spherical-geometry/render.py --stills-only
```

Видео, аудио и машинные отчёты исключены из Git локальным `.gitignore`.
