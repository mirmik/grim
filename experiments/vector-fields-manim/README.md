# Видео к главе «Векторные поля и проблема сравнения»

Наглядное введение перед чтением главы: 3:18, семь сцен. Начинаем с карты
ветра и сравнения стрелок, затем показываем касательные плоскости,
развёртку цилиндра, вращающиеся оси и проекцию производной. В конце
сопоставляем постоянную и поворачивающуюся стрелки на одном цилиндре:
это даёт картину параллельного переноса и переход к геодезическим.
Формулы служат обозначениями происходящего; выводы остаются в книге.

- [Готовый ролик](output/vector-fields-and-comparison.mp4)
- [Сценарий](script.json) · [анимация](lesson.py) · [геометрия](geometry.py)
- [Текст диктора](output/narration.md) · [субтитры](output/subtitles.vtt)

Графика — Manim Community 0.21.0, Cairo, Text и MathTypst. Используется
окружение и планировщик кадров из `../spherical-geometry-manim`.
Все семь сцен и их озвучка созданы для этой главы.

Озвучка — VoxCPM2 (`openbmb/VoxCPM2`, версия пакета 2.0.3), прежний
образец `~/project/for-tts-xtts/reference.wav`. Каждая сцена синтезируется
целиком: cfg 2.0, 10 шагов, seed 42, max_len 700, без normalize, denoise
и retry_badcase. Внутри записей нет склеек или ускорения. Между ними
добавлено 0,35 с; итоговая звуковая дорожка до кодирования сохраняет
сэмплы каждого исходного WAV без изменений. При сборке AAC нормализуется громкость.
Whisper small используется для проверки распознанного текста и привязки
39 отключаемых субтитров; распознавание не оценивает интонацию и ударения.
Указанные в исходном synthesis-report 204,09 с относятся к монтажу
общего синтезатора; prepare_audio собирает окончательные 197,79 с.

Развёртка задаётся изометрическим семейством
`r(s,z,k) = (sin(ks)/k, (cos(ks)-1)/k, z)` с плоским пределом при k=0.
Его метрика — `ds² + dz²`. Для поля
`V = cos(β)e_s + sin(β)e_z` производная разделяется на касательную
часть `β′(−sin(β)e_s + cos(β)e_z)` и нормальную `−k cos(β)n`.
При постоянном β касательная часть нулевая. В последней сцене радиус
равен единице; на правом цилиндре β линейно меняется вдоль маршрута.
Проекция описывает связность для поверхности с метрикой, индуцированной
обычным евклидовым пространством. Для геодезической на экране оговорена
постоянная скорость. Содержание сверено с главой книги и
[конспектом Дэвида Тонга, §§3.2–3.3](https://www.damtp.cam.ac.uk/user/tong/gr/grhtml/S3.html).

## Воспроизведение сборки

```bash
bash experiments/vector-fields-manim/run.sh
python3 experiments/vector-fields-manim/install.py
PLAYWRIGHT_BROWSERS_PATH=/tmp/grim-playwright node experiments/vector-fields-manim/verify_player.mjs
```

Для синтеза нужны локальные веса и доступ к CUDA. Окружения Manim и
VoxCPM2 используются из предыдущих экспериментов; для проверки речи
нужен локальный Whisper small. Синтезатор повторно использует WAV,
если совпадают текст, модель, настройки и образец голоса.

Установка требует успешного `validate.py`, находит зарегистрированную
книгу «Дифференциальная геометрия» и добавляет видео после вводного
абзаца нужной главы. Ассеты находятся в книге, в `assets/video/`.
Общий проигрыватель совместим с видео к предыдущей главе.
Есть постер, русские субтитры, переходы к пяти частям и скачивание;
автоматический старт отключён. MP4: 1080p, 30 кадров/с, H.264 Baseline
без B-кадров, BT.709, AAC, faststart.

`validate.py` проверяет геометрические тождества, фактические кадры
MP4 относительно снимков Manim, движение стрелок, изменение числовых
компонент, анимацию на развёртках, целостность WAV и полное декодирование.
`verify_player.mjs` проверяет установленное видео в Grim: воспроизведение,
перемотку, субтитры, полноэкранный режим, скачивание, HTTP Range
и мобильную вёрстку. Отчёты и снимки находятся в `output/`.
