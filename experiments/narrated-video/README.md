# Учебный ролик: от окружности к синусоиде

Законченный прототип на русском языке: около 78 секунд, 1920×1080, 30 кадров/с,
H.264 + AAC. Озвучка синтетическая, XTTS v2 с существующим образцом
`~/project/for-tts-xtts/reference.wav`.

Открыть результат: [MP4](output/sine-explained-ru.mp4).
Дополнительно: [раскадровка](output/storyboard.jpg),
[озвучка WAV](output/narration.wav), [субтитры SRT](output/subtitles.srt).

## Как повторить

Из корня Grim:

```bash
bash experiments/narrated-video/run.sh
```

Использует готовое окружение `~/project/for-tts-xtts/venv`, сохранённую модель
`~/.local/share/tts/tts_models--multilingual--multi-dataset--xtts_v2` и GPU
при наличии. Сервис XTTS запускать не требуется. В исходный проект XTTS
ничего не записывается; все результаты находятся в `output/` и исключены из Git.

Второй Python (по умолчанию `python3`) требует Pillow. Проверено с Pillow 12.3.0;
также требуются FFmpeg с libx264 и шрифты DejaVu Sans в стандартном Linux-пути.
`XTTS_PYTHON` и `VIDEO_PYTHON` переопределяют интерпретаторы. Для другого
расположения голоса/модели: аргументы `--xtts-root` и `--model-dir`.

## Устройство

- `script.json` — текст рассказчика, заголовки, последовательность сцен.
- `synthesize.py` — прямая генерация через установленный XTTS с теми же
  адаптерами совместимости PyTorch/torchaudio, что и в существующем сервисе.
  Отдельный WAV и кеш на реплику, короткие паузы, фактические длительности.
- `render.py` — анимация окружности, проекции и графика на Pillow, кадры
  передаются напрямую в FFmpeg; озвучка нормализуется по громкости.
- `output/timeline.json` — реальные границы речи и сцен.
- `verify_speech.py` — необязательная независимая проверка речи через
  faster-whisper. Скачивает Whisper base (или `--model small`) в
  `/tmp/grim-video-whisper`; распознаёт локально, сохраняет
  `output/speech-check.json`.

```bash
# Только раскадровка, без кодирования видео:
python3 experiments/narrated-video/render.py --stills-only
# Пересобрать видео с существующей озвучкой:
python3 experiments/narrated-video/render.py
```

## Границы прототипа

Это отдельный эксперимент, без интеграции в интерфейс Grim. Здесь используется
Pillow, а не Manim: проверяется полный путь от сценария и локального XTTS
до готового учебного видео без установки нового анимационного окружения.

Границы сцен следуют фактической длительности реплик. Субтитры отдельных
предложений распределены внутри реплики приблизительно по числу слов;
анимация внутри сцены поставлена вручную. Это не синхронизация по словам.
Небольшая модель распознавания помогает найти грубые пропуски речи, но
не заменяет оценку интонации и ударений человеком.

Кеш озвучки учитывает текст, путь модели, хеш образца голоса, seed и настройки
синтеза. После замены весов на месте удалите соответствующие WAV/JSON из
`output/`. Повторяемость точных отсчётов между версиями CUDA не гарантируется.
