# Эксперименты с озвучкой и учебными видео

В Git хранятся исходники экспериментов: сценарии `script.json`, тексты
и настройки проб, Python-код, скрипты запуска и проверки, CSS/JS
проигрывателя, закреплённые зависимости и README с наблюдениями.
`qwen3-omni/model.json` задаёт ревизию скачиваемой модели и используется
скриптами; он также входит в исходники.

Каталоги `output/`, `output-*/` и `media/` содержат результаты запуска:
аудио, видео, кадры, субтитры, временные шкалы, страницы сравнения
и отчёты. Они исключены локальными `.gitignore`, как и окружения
`.venv/`, скачанные модели `models/`, библиотеки `.native/` и кеши.
Ссылки на результаты в README работают после соответствующей сборки.
Копии конфигурации Qwen3-Omni рядом с исходниками тоже игнорируются:
`download.py` скачивает их вместе с закреплённой моделью в `models/`.

## Связи между экспериментами

- `narrated-video` и `beam-bending` — ранние пробы видео и озвучки.
  Скрипты VoxCPM2, проверки речи и привязки субтитров из `beam-bending`
  используются и в последующих роликах.
- `qwen-tts`, `voxcpm2` и `qwen3-omni` — сравнения синтеза речи.
  VoxCPM2 использует тексты из `qwen-tts`; Omni сравнивается со сценой
  из `surface-bending-manim`.
- `spherical-geometry` и редакции `spherical-geometry-v2`–`v6` сохраняют
  исходные сценарии и варианты анимации. Это отдельные редакции,
  а не результаты рендера. В README v2 находятся пояснения и источники,
  на которые ссылаются последующие редакции.
- `spherical-geometry-manim` использует озвучку и временную шкалу v6.
  Перед его `run.sh` нужно подготовить результаты v6 по её README.
- `surface-bending-manim` и `vector-fields-manim` используют окружение
  и базовый класс сцен из `spherical-geometry-manim`, синтезатор из
  `beam-bending` и окружение `voxcpm2`. Они генерируют собственную озвучку.

Команды установки и запуска находятся в README каждого эксперимента.

## Данные за пределами Git

Клона репозитория недостаточно для немедленной пересборки всех опытов.
Нужны окружения, модели и системные инструменты из соответствующих README;
для синтеза используется CUDA. Несколько скриптов ожидают уже скачанный
Whisper small в `/tmp/grim-video-whisper` и запускаются в offline-режиме.

Образец голоса `~/project/for-tts-xtts/reference.wav` — внешний исходный
файл, который эти скрипты не создают. Его нужно сохранять отдельно.
Ранние опыты с XTTS также используют внешнее окружение и кеш модели.
Повторная генерация позволяет получить материалы заново, но совпадение
каждой записи, таймингов и измерений между разными окружениями не гарантируется.

Локальная библиотека `~/.grim/` находится вне Git-репозитория приложения.
Другой путь можно задать через `GRIM_LIBRARY`. Её реестр
и тексты книг не восстанавливаются скриптами экспериментов: `install.py`
добавляет видео в уже существующие главы. Книги требуют отдельного
сохранения вместе с их исходниками и ресурсами.
