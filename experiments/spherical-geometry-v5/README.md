# Кривизна изнутри — маршрут показывается один раз

[Видео MP4](output-voxcpm-scenes/spherical-geometry-ru.mp4) ·
[RGB WebM для VLC](output-voxcpm-scenes/spherical-geometry-rgb.webm) ·
[Текст нового начала](opening.md)

В четвёртой редакции до движения стрелки проходило 97 секунд: маршрут
отдельно описывался при построении треугольника, затем повторялся при обходе.
Здесь построение объединено с движением. Короткая постановка вопроса
и правило переноса занимают 22 секунды. Сам обход сохранён вместе с его
озвучкой, остановками в вершинах и паузой для сравнения направлений.
Цветной след появляется по мере прохождения пути.

- 00:00 — вопрос, цель опыта и правило переноса.
- 00:22 — движение стрелки; маршрут объясняется по ходу движения.
- 00:57 — результат, геодезические и угловой избыток.
- 01:27 — связь с площадью и дальнейшее объяснение кривизны.

Полная длительность — 7:55. VoxCPM2 озвучивает целые сцены прежним голосом.
Перезаписаны две сцены: постановка опыта и переход к угловому избытку.
Остальные 16 исходных записей сохранены. Скорость аудио не меняется.

`validate.py` проверяет геометрию, тайминг, сборку исходных записей
и полное декодирование MP4. `check_frames.py` сравнивает кадры готового
видео с рендером и проверяет три положения движущейся стрелки.

MP4 использует H.264 Constrained Baseline / BT.709. Запасной WebM использует
VP9 Profile 1 RGB, без потерь на этапе повторного кодирования. Он позволяет
проверить другой путь воспроизведения в VLC; устранение артефактов
на пользовательском видеовыводе пока не подтверждено.

Полная сборка:

```bash
bash experiments/spherical-geometry-v5/run.sh
```

Запуск VLC с программным декодированием и X11-выводом:

```bash
bash experiments/spherical-geometry-v5/play-vlc-software.sh
```
