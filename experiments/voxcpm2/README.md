# VoxCPM2: локальная проба русской озвучки

[Страница сравнения с Qwen и XTTS](output/index.html).

[Сравнение цельного абзаца и разбиения по предложениям](output/sentences/index.html).

Для варианта с разбиением:

```bash
HF_HUB_OFFLINE=1 TQDM_DISABLE=1 experiments/voxcpm2/.venv/bin/python experiments/voxcpm2/synthesize.py --split-sentences
python3 experiments/voxcpm2/review_sentences.py
```

В объяснении балки — 14 предложений, в пробе терминов — 3; каждый фрагмент
синтезируется отдельным вызовом с теми же параметрами и seed 42.
Во всех трёх режимах между сырыми WAV добавляется ровно по 0,2 с тишины.
Тишина и речевые хвосты внутри исходных записей не обрезаются. Инструкция
«спокойно» в соответствующем режиме повторяется перед каждым предложением.

Исходные куски, их тексты, временные границы и хеши сохранены в
`output/sentences/chunks/` и `output/sentences/report.json`. Проверка сборки
сопоставляет каждый кусок с итоговым WAV посэмплово и проверяет добавленные
паузы. На странице есть парные плееры для всех режимов; старая озвучка
целыми абзацами сохранена. Длительность объяснения с разбиением:
46,92 с (clone), 46,76 с (calm), 57,16 с (continuation).

Шесть записей: связный фрагмент по сопромату и термины с «синусоидой» в трёх
режимах. Тексты берутся из `../qwen-tts/samples.json`, образец — прежний
`~/project/for-tts-xtts/reference.wav`. Числа в сценарии развёрнуты в слова;
предложения синтезируются одним абзацем, без монтажа.

- `clone`: только `reference_wav_path`, перенос голоса без текстового образца.
- `calm`: тот же режим плюс инструкция в скобках перед текстом:
  `Calm explanatory tone, moderate pace, clear articulation and natural pauses.`
- `continuation`: тот же WAV передаётся и как `reference_wav_path`, и как
  `prompt_wav_path`, вместе с транскрипцией `../qwen-tts/reference.txt`.

Модель [openbmb/VoxCPM2](https://huggingface.co/openbmb/VoxCPM2), revision
`32279effe8c19989596f05d353d1447f51d9e915`.
[Официальный проект и описание режимов](https://github.com/OpenBMB/VoxCPM).
Python 3.12.7, voxcpm 2.0.3, torch/torchaudio 2.10.0, torchcodec 0.10.0,
transformers 4.57.3. Полный состав окружения — `requirements.lock.txt`.

## Пересборка

Из корня grim:

```bash
UV_CACHE_DIR=/tmp/grim-qwen-uv uv venv --python 3.12 experiments/voxcpm2/.venv
UV_CACHE_DIR=/tmp/grim-qwen-uv UV_LINK_MODE=copy uv pip install \
  --python experiments/voxcpm2/.venv/bin/python \
  -r experiments/voxcpm2/requirements.lock.txt
HF_HUB_OFFLINE=1 experiments/voxcpm2/.venv/bin/python experiments/voxcpm2/synthesize.py
python3 experiments/voxcpm2/review.py
```

Для первого скачивания модели убрать `HF_HUB_OFFLINE=1`. Синтезу нужен доступ
к CUDA GPU. `review.py` использует системный Python с faster-whisper,
локальный Whisper small в `/tmp/grim-video-whisper` и ffmpeg.

CFG 2.0, 10 шагов диффузии, seed 42 перед каждой генерацией, max_len 700.
В установленной версии 2.0.3 аргумента `seed` у generate ещё нет: он задаётся
через `transformers.set_seed`, в отличие от текущего примера в upstream README.
Отключены torch.compile, шумоподавление образца, нормализация текста и
автоматические повторные попытки. Время измерено без компиляции и включает
подготовку образца для каждого вызова. Выход 48 кГц; сырые WAV float32,
прослушиваемые MP3 нормализованы до целевых −18 LUFS, как предыдущие образцы.

## Результат первого прогона

| Режим | Балка, с | Термины, с | Синтез балки, с |
| --- | ---: | ---: | ---: |
| Перенос голоса | 39,04 | 12,32 | 11,91 |
| Спокойное объяснение | 30,08 | 12,96 | 7,73 |
| Продолжение образца | 40,96 | 13,60 | 10,33 |

RTX 5090, максимальная память, выделенная PyTorch: 6,49 GiB. Это не полный
расход памяти процесса. Загрузка модели — 6,46 с.

**Неудачная проба:** в `calm-beam.wav` распознавание заканчивается на фразе
про момент у стены. Нет двух заключительных предложений о максимальных
напряжениях и результате 37,5 МПа; запись действительно существенно короче.
Она сохранена без замены, чтобы не скрывать неудачу управления стилем.
Обычный режим и продолжение содержат окончание объяснения, но в ASR тоже
есть ошибки/расхождения в терминах и окончаниях.

`output/report.json` содержит параметры, времена и хеши WAV;
`speech-check.json` — распознанный текст и временные метки;
`validation.json` — результат проверки исходных хешей и декодирования файлов.
Качество голоса, ударения и интонация не оценивались прослушиванием агентом;
Whisper не заменяет такую оценку. Улучшение относительно Qwen не утверждается.
