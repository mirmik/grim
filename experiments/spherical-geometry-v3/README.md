# Кривизна изнутри — перенос стрелки снова в начале

[Ролик MP4](output-voxcpm-scenes/spherical-geometry-ru.mp4) ·
[Запасной RGB WebM](output-voxcpm-scenes/spherical-geometry-rgb.webm) ·
[Субтитры](output-voxcpm-scenes/subtitles.srt)

Третья редакция возвращает опыт со стрелкой сразу после построения
сферического треугольника. Сначала зритель видит неожиданный поворот,
потом получает объяснение через угловой избыток и кривизну.
В поздней части повтор этой сцены убран.

Перенос начинается в сцене с **00:39**, обсуждение избытка — примерно
с **01:02**. Весь ролик — **7:55**. Переписана и заново озвучена только
сцена переноса; остальные 18 записей сохранены из второй редакции.
VoxCPM2 читает каждую сцену целиком, прежним голосом и с теми же настройками.

Движение стрелки идёт во время первых двух предложений сцены. После
возвращения к полюсу появляются сравнение с исходной меткой и подпись
поворота на 90°. Начальная и конечная позиции вычисляются аналитически.

`check_frames.py` дополнительно проверяет **три фазы движения в готовом
видеофайле**: стрелка проходит обе стороны и экватор. Изменение проверяется
внутри панели со сферой, без субтитров и полосы прогресса, чтобы статичная
сцена не могла пройти проверку за счёт смены текста. Также сохранены
сравнения кадров с рендером, проверки геометрии, аудио и декодирования.

Основной файл — H.264 Constrained Baseline с явной матрицей BT.709.
Запасной — VP9 Profile 1 RGB, без потерь на этапе повторного кодирования.
Он предназначен для проверки воспроизведения в VLC, где пользователь
видел цветные артефакты у первой редакции. На стороне пользовательского
видеовывода устранение проблемы пока не подтверждено.

Для запуска VLC без аппаратного декодирования и с X11-выводом:

```bash
bash experiments/spherical-geometry-v3/play-vlc-software.sh
```

Постоянные настройки VLC не меняются.

Полное воспроизведение сборки:

```bash
bash experiments/spherical-geometry-v3/run.sh
```

Сценарий — [script.json](script.json). Математические пояснения, источники
и параметры проверок описаны во [второй редакции](../spherical-geometry-v2/README.md).
Предыдущие версии сохранены без изменений.
